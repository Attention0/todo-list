# MPC size-curve story discovery workplan

## 0. Purpose

This file defines a new exploratory analysis pass for the consumer-survey project.

The goal is **not** to continue optimizing the current NHB-style heterogeneity / person-versus-context story. The goal is to return to the most basic economic object in the survey — the marginal propensity to consume (MPC) — and ask whether the randomized 3×3 design reveals a simple, surprising, economically interpretable reduced-form fact strong enough to organize a Nature Communications paper.

The main candidate is:

> **Transfer design reshapes the size dependence of the marginal propensity to consume.**
>
> Stated MPC appears to decline with transfer size for liquid cash, while the corresponding amount gradient is strongly attenuated or absent for earmarked medical wealth.

This is a **candidate**, not a conclusion. The analysis must be designed so that it can clearly kill this story if the differential slope is imprecise, outcome-coding dependent, or mechanically generated by the survey response categories.

Do not modify the manuscript in this pass.

Relevant existing work:
- PR #3 contains the main consumer-survey audit, first look, heterogeneity, prediction, HTE and Nature-style analysis.
- PR #8 establishes a crucial identification fact: each of the 5,497 respondents answers exactly one of the nine MPC scenarios, so within-person cross-form MPC profiles and individual latent fungibility traits are not identified.
- Existing first-look results already show a visually interesting amount pattern, but the original unrestricted 4-df type×amount omnibus interaction test is not strong enough to support a headline conclusion by itself.

The analysis should therefore focus on the randomized 3×3 design and a small number of theory-driven extensions.

---

## 1. Experimental object and known descriptive pattern

The randomized experiment crosses:

### Transfer form
1. Cash
2. Food / daily-consumption voucher, valid for six months and non-cashable
3. Medical personal-account top-up, long-lived and restricted to medical-related spending

### Transfer amount
1. RMB 200
2. RMB 1,000
3. RMB 5,000

Each respondent sees exactly one cell.

Current midpoint-coded cell means from the first-look analysis are approximately:

| Form | RMB 200 | RMB 1,000 | RMB 5,000 |
|---|---:|---:|---:|
| Cash | 0.253 | 0.227 | 0.201 |
| Food | 0.228 | 0.201 | 0.195 |
| Medical | 0.177 | 0.179 | 0.179 |

The corresponding ordinal means also show:
- Cash: 2.934 → 2.803 → 2.702
- Food: 2.785 → 2.669 → 2.628
- Medical: 2.462 → 2.531 → 2.520

Existing first-look facts:
- Cash has a clear negative 200→5,000 gradient.
- Food has a smaller negative gradient.
- Medical is visually flat.
- The previous unrestricted four-interaction Wald test gives p≈0.166, so the visual pattern is not yet a validated paper result.

The new analysis must test the **economically structured trend hypothesis**, rather than only the unrestricted omnibus hypothesis.

# PART I. HEADLINE QUESTION: DOES TRANSFER FORM CHANGE THE MPC–TRANSFER-SIZE CURVE?

## 2. Primary estimands

Because 200 → 1,000 → 5,000 multiplies the amount by exactly five at each step, log(amount) is equally spaced across the three randomized amount levels.

Define a centered transfer-intensity variable, for example:

[
z_A in {-1,0,1}
]

corresponding to RMB 200, 1,000 and 5,000. This is algebraically equivalent to a centered linear trend in log(amount).

The core specification should be:

[
Y_i =
alpha
+ eta z_{A_i}
+ gamma_F Food_i
+ gamma_M Medical_i
+ delta_F(Food_i	imes z_{A_i})
+ delta_M(Medical_i	imes z_{A_i})
+ arepsilon_i
]

where Cash is the omitted form.

Report directly:

1. Cash amount slope: (eta)
2. Food amount slope: (eta+delta_F)
3. Medical amount slope: (eta+delta_M)
4. Food−Cash differential slope: (delta_F)
5. Medical−Cash differential slope: (delta_M)
6. Medical−Food differential slope: (delta_M-delta_F)

The most important test for the headline story is:

> Is the Medical−Cash differential amount slope positive and large enough to imply that the usual negative cash MPC-size gradient is substantially attenuated or absent for the medical account?

Do not equate “Medical slope statistically insignificant” with “Medical is flat.” The relevant evidence is the **difference in slopes**.

### Inference
For all headline coefficients report:
- point estimate;
- HC1 or HC3 robust SE;
- 95% CI;
- unadjusted p-value;
- Holm-adjusted p-value within the small primary slope family;
- randomization/permutation inference if computationally feasible.

Permutation/randomization inference should respect the randomized design. Do not permute baseline covariates. The cleanest approach is to permute the nine randomized treatment labels while preserving cell counts, or equivalently permute amount labels within form only if that matches the intended null being tested. Document the exact null and permutation scheme.

---

## 3. Outcome hierarchy

The analysis must not rely on one arbitrary midpoint mapping.

### Primary outcome
Use the original six-category ordered stated-consumption response.

Run:
- linear ordinal-score model for transparent coefficients;
- ordered logit;
- ordered probit.

The ordinal linear model is acceptable as a reduced-form trend summary but should not be interpreted as cardinal MPC.

### Auxiliary economic visualization
Use the existing midpoint mapping:
- 0
- 0.05
- 0.175
- 0.375
- 0.625
- 0.875

Also repeat with the alternative top-bin coding used in prior work, including top category = 1.0.

### Threshold outcomes
Create the same cumulative thresholds already used in the project:
- any additional spending;
- MPC ≥ 10%;
- MPC ≥ 25%;
- MPC ≥ 50%;
- top category / >75%.

Estimate the same form×amount trend structure for each threshold.

This serves two purposes:
1. tests whether the headline curve is robust to outcome representation;
2. reveals which part of the MPC distribution generates the amount gradient.

---

## 4. Nonparametric shape checks

The linear log-amount trend is the economically disciplined main test, but it must not hide a nonlinear pattern.

For each form also estimate unrestricted amount indicators and report:
- 1,000 − 200;
- 5,000 − 1,000;
- 5,000 − 200.

Then compare:
- whether both adjacent cash changes are negative;
- whether medical changes are small and offsetting;
- whether the Medical−Cash difference emerges in both adjacent intervals or is driven by only one jump.

Do not require perfect linearity, but clearly distinguish:
- a genuine monotone amount gradient;
- a one-cell anomaly;
- a U-shape / reversal;
- a flat response.

A useful robustness parameterization is simply amount rank (-1,0,1), which avoids overinterpreting the natural-log functional form.

---

# PART II. MPC DISTRIBUTION ANATOMY

## 5. Why the mean is not enough

The six-bin outcome has a large mass at “basically no additional consumption.” A changing mean can arise from very different behavioral shifts.

For every form×amount cell report:
- full six-category probability vector;
- CDF;
- complementary CDF / threshold probabilities;
- mean ordinal score;
- midpoint mean;
- median category;
- floor share;
- top-category share.

The key question is:

> When transfer size rises, which parts of the distribution move for Cash, Food and Medical?

---

## 6. Threshold-response curves

For each of the five cumulative binary outcomes, plot response probability against amount separately for Cash, Food and Medical.

Examples:
- (P(Y>0))
- (P(MPCge10%))
- (P(MPCge25%))
- (P(MPCge50%))
- (P(MPC>75%))

For each threshold estimate:
- Cash amount slope;
- Food amount slope;
- Medical amount slope;
- Medical−Cash differential slope.

Interpretation:
- If Cash’s declining average MPC mainly comes from the high-MPC tail shrinking while (P(any spending)) is stable, then the amount effect is mainly an intensive / tail compression pattern.
- If the floor share changes strongly, then the extensive margin is important.
- If Medical’s flat mean hides offsetting movements across thresholds, “flat MPC” should not be described as behavioral invariance.

Avoid conditioning on post-treatment outcomes such as “only among people who spend something” as a causal estimand. Conditional-positive summaries may be shown descriptively, but the main distributional evidence should use unconditional threshold probabilities.

---

## 7. Probability-shift decomposition

Use the midpoint representation only as a transparent decomposition identity:

[
E[MPC] = sum_k m_k P(Y=k)
]

For each form, decompose the 200→5,000 change in midpoint MPC into contributions from changes in the six response-category probabilities.

Produce a table showing, for each category:
- (P_{5000}(k)-P_{200}(k));
- midpoint weight (m_k);
- contribution to the total mean-MPC change.

This is not a structural decomposition. It is a descriptive accounting exercise to identify which probability masses generate the amount slope.

A particularly useful visual would show whether Cash’s decline is driven by:
- fewer top-bin respondents;
- more floor respondents;
- movement from high to middle categories;
while Medical exhibits a different redistribution.

# PART III. SECOND LAYER: WHY MIGHT THE CURVES DIFFER?

These analyses are **secondary mechanism layers**. They should support or reject interpretations of the headline reduced-form fact. They must not replace it.

Do not conduct an unrestricted scan over all 41 predictors.

---

## 8. Food: inframarginality / budget-set logic

Existing project code already constructs conservative six-month food-spending bounds and identifies “definitely inframarginal” households.

Use this as the main Food mechanism check.

### Main questions
1. Within definitely inframarginal households, is Food still below Cash on average?
2. Within definitely inframarginal households, does Food exhibit the same negative amount slope as Cash?
3. Does the Food−Cash differential slope change after restricting to definitely inframarginal households?
4. Is any Food amount pattern mechanically driven by the very small likely-binding subgroup?

Do **not** headline the likely-binding group because the existing sample there is extremely small.

Run sensitivity using plausible lower/upper-bound definitions already present in the project. Do not invent precise six-month spending levels from open-ended categories.

Interpretation discipline:
- If Food differs from Cash even when clearly inframarginal, this is evidence against a simple budget-set-only explanation.
- It is not by itself proof of mental accounting, labeling, salience or commitment.

---

## 9. Medical: need–resource matching

Past annual out-of-pocket medical spending is only a proxy for medical need / exposure. It is not a strict bindingness measure because the medical account is long-lived.

Use this variable to ask:

> Does earmarked medical wealth become more cash-like for households with greater expected relevance of the medical category?

### Specifications
Use:
- a transparent standardized linear trend in prior medical spending;
- a coarse, pre-specified low / middle / high grouping for visualization.

Estimate models including:
- Medical × need;
- amount trend × need;
- Medical × amount trend × need.

Key questions:
1. Is the Medical−Cash average gap smaller among higher-need households?
2. Is the flat Medical amount slope concentrated among low-need or high-need households?
3. Does need matching explain any part of the Medical−Cash differential amount slope?

Do not claim causal moderation by medical need. The randomized variables are form and amount; baseline need is observational.

---

## 10. Cross-domain “matching” check

To assess whether need matching is a coherent concept rather than an isolated medical correlation, compare:

- Food form × baseline food spending;
- Medical form × baseline medical spending.

The goal is not to force symmetry.

Ask:
- Do higher baseline category needs make the corresponding restricted resource behave more like Cash?
- Is the sign direction similar across Food and Medical?
- Does the evidence survive clean-sample and ordinal-outcome checks?

If Food and Medical show different patterns, report that difference rather than combining them into a single fungibility index.

---

# PART IV. CLASSIC MPC DETERMINANTS AS BENCHMARKS

## 11. Small, theory-driven benchmark set only

Use only a minimal set of baseline variables with clear economic relevance:

1. emergency liquidity / ability to raise funds;
2. income;
3. baseline category spending;
4. prior subsidy experience.

Potentially include housing / household size only if already central to the prior economic specification, but do not expand this section into a general moderator search.

### Questions
A. Does the cash MPC-size slope vary with liquidity?
B. Is diminishing MPC with amount stronger among liquid or illiquid households?
C. Does that classic slope heterogeneity itself differ by transfer form?
D. Can standard liquidity/income mechanisms account for the apparent Medical flatness?

This is useful because it separates:
- a generic household-finance explanation;
from
- a genuinely transfer-design-specific curve.

If the Medical curve remains different after allowing theory-driven liquidity heterogeneity, that strengthens the reduced-form design story.

# PART V. MODEL COMPARISON

## 12. Nested economic specifications

Compare at least three models.

### Model 1: additive
[
Y sim form + amount
]

### Model 2: form-specific amount curves
[
Y sim form 	imes amount_trend
]

### Model 3: form-specific curves plus small theory block
[
Y sim form 	imes amount_trend + need/liquidity interactions
]

Use:
- in-sample fit only as descriptive;
- AIC/BIC where model family permits;
- out-of-sample prediction as secondary evidence.

Do not make predictive performance the paper contribution.

The main purpose is to ask:
- Does allowing form-specific amount slopes materially improve the representation of the data?
- Do need/liquidity interactions explain the same structure, or is the form×amount curve still necessary?

---

## 13. Limited machine-learning diagnostic

ML may be used only as a diagnostic for missed nonlinearity.

Recommended:
- shallow regression tree;
- random forest;
- histogram gradient boosting.

Use exactly the same theory-limited feature set plus randomized form and amount.

Questions:
1. Does a flexible model repeatedly split first on form and amount?
2. Does the learned form×amount surface resemble the simple trend model?
3. Are there strong nonlinearities that make the linear trend misleading?

Do not use:
- SHAP ranking as substantive evidence;
- unrestricted 41-variable discovery as the story;
- post-hoc CATE subgroups as headline results.

If ML finds a radically different structure, return to the raw cell means and explain it rather than building a black-box narrative.

# PART VI. ROBUSTNESS AND MEASUREMENT THREATS

## 14. Sample definitions

Repeat the headline slope estimates in at least:
- Raw sample R;
- Adult sample A;
- Clean candidate sample C;
- Q1/Q2 response-quality screens only as secondary sensitivity, because these screens are post-randomization sample restrictions and much smaller.

Focus on stability of:
- sign;
- effect size;
- differential slope;
not just significance.

---

## 15. Survey-outcome structure

The outcome is:
- hypothetical;
- stated;
- six-category;
- top-coded;
- floor-concentrated.

Therefore explicitly test whether the curve could be an artifact of the elicitation scale.

Required checks:
1. ordinal score;
2. ordered logit/probit;
3. midpoint;
4. alternative top-bin midpoint;
5. cumulative threshold outcomes.

If the Medical-vs-Cash differential slope exists only under one midpoint mapping and disappears in ordinal / threshold representations, **kill the headline story**.

Also inspect whether higher transfer amounts mechanically make it harder to choose a high percentage category because respondents think in absolute yuan rather than percentages. This cannot be fully solved with current data, but it must be discussed as a measurement alternative.

---

## 16. Covariate adjustment

Because assignment is randomized, unadjusted estimates are primary.

Also report a precision-adjusted version using the same pre-treatment controls already defined in the project.

Adjustment is a robustness / precision exercise, not identification.

Do not select controls based on significance.

---

## 17. Multiplicity

Define a small primary inferential family before running the new analysis:

1. Cash amount slope;
2. Food amount slope;
3. Medical amount slope;
4. Food−Cash differential slope;
5. Medical−Cash differential slope.

Report raw and Holm-adjusted p-values.

All mechanism and moderator analyses are secondary exploratory evidence and should be labeled as such.

# PART VII. STORY DECISION RULES

## 18. When the headline story survives

The statement

> “Transfer design reshapes the size dependence of stated MPC: MPC declines with transfer size for cash, but the gradient is attenuated or absent for earmarked medical wealth.”

is considered strongly supported only if most of the following hold:

1. Cash amount slope is clearly negative.
2. Medical amount slope is much closer to zero.
3. Medical−Cash differential slope is positive with reasonably narrow uncertainty.
4. The differential slope is not driven by one anomalous cell.
5. The pattern survives raw/adult/clean samples.
6. The pattern survives ordinal, midpoint, alternative-top and several threshold outcomes.
7. Distributional anatomy provides an interpretable reason for the different slopes.
8. The result is not eliminated by a small set of standard liquidity / need controls.
9. The main pattern is visible directly in the randomized 3×3 cell data without relying on ML.

If these conditions hold, the simple 3×3 figure should be able to carry the paper's opening empirical fact.

---

## 19. When to downgrade or kill it

### Kill the story if:
- Medical−Cash differential slope is essentially zero with a narrow CI;
- the sign flips across reasonable outcome codings;
- the result is entirely generated by the arbitrary top-bin midpoint;
- only one response-quality subsample supports it;
- one single cell drives the entire gradient;
- the raw threshold distributions do not support any coherent distributional difference.

### Downgrade to “suggestive” if:
- point estimates are economically interesting but differential-slope CIs remain wide;
- ordinal evidence is directionally consistent but threshold evidence is weak;
- the pattern is robust descriptively but underpowered for a strong interaction claim.

Do not rescue a failed curve story by switching to a large moderator search.

# PART VIII. SECONDARY STORIES TO EXPLORE

These are explicitly subordinate to the size-curve story.

## 20. Secondary story A: restrictions can reduce consumption even when inframarginal

Existing first-look evidence suggests Food may be below Cash even among definitely inframarginal households.

Re-estimate this carefully and ask:
- whether it is robust across outcome coding;
- whether it varies with amount;
- whether it helps explain the Food size curve.

Do not frame this as “mental accounting proven.”

---

## 21. Secondary story B: need matching changes fungibility

Use Food spending and medical spending as category-specific need proxies.

Ask whether restricted resources behave more like Cash when they match pre-existing household needs.

This is a mechanism layer, not an independently randomized causal mechanism.

---

## 22. Secondary story C: transfer design changes the margin of response

Use the distributional analysis to determine whether different forms affect:
- the probability of any additional consumption;
- the probability of high MPC;
- the upper tail versus middle categories.

This can become an important second panel / second result if it explains **why** the amount curves differ.

# PART X. RESEARCH DISCIPLINE

## 27. Claims that are not allowed from current design

Do not claim:
- realized MPC;
- welfare effects;
- stable individual fungibility traits;
- within-person context switching;
- causal effects of income, education, medical need or psychological traits;
- that Medical “causes precautionary saving” without a direct mechanism design;
- that a non-significant Medical slope proves exact flatness;
- that one significant interaction establishes a universal behavioral law.

Use “stated MPC” throughout.

---

## 28. The standard for a successful story

The target is not “many significant findings.”

The target is one fact that can be explained to a non-specialist in a few sentences:

> For cash, giving more money appears to reduce the fraction of each additional yuan people say they would spend. But when the same nominal resource is placed in a long-lived medical account, that familiar size gradient largely disappears. The experiment asks whether the MPC is therefore not only a property of households and transfer size, but also of the economic form in which resources arrive.

Everything else in this workplan should either:
- validate this fact;
- explain its distributional origin;
- provide a plausible second layer;
- or kill it cleanly.

That is the purpose of this analysis pass.
