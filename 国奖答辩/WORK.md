# 国奖答辩 PPT — Work Instructions

## Objective

根据 `国奖答辩/SPEC.md` 制作一份可直接用于北京大学国家发展研究院研究生国家奖学金 3 分钟答辩的 PPT。

先完整阅读 `SPEC.md`，它是内容边界、视觉规范和事实口径的 source of truth。

本轮目标是 **先做一版结构与视觉都完整的 V1，再做一次仅针对排版、留白、图片和字号的 V2 微调**。不要在制作过程中擅自扩写经历或增加未经确认的荣誉。

最终建议输出：

- `国奖答辩/国奖答辩_v1.pptx`
- `国奖答辩/国奖答辩_v1.pdf`
- 经过检查后的 `国奖答辩/国奖答辩_final.pptx`
- `国奖答辩/国奖答辩_final.pdf`
- 如环境允许，另存一份 `国奖答辩/SPEAKER_NOTES.md`，记录逐页讲稿与时间。

# Task 0 — 资产盘点与准备

在开始画版式前，先盘点可访问素材。

优先寻找：

1. 北京大学 / 国家发展研究院官方 Logo；
2. 中国人民大学官方 Logo；
3. 香港大学官方 Logo；
4. 交换或冯氏奖学金的真实证明/照片；
5. 两篇毕业论文的封面、摘要页、研究图或可展示的数据/识别示意；
6. 班级、团支部或党支部真实活动照片；
7. 三好学生、优秀共青团员、优秀毕业生等证书或官方截图。

原则：

- 有真实证明图就用真实图；
- 没有则用官方 Logo / 极简图标替代；
- 不得伪造证书、论文结果图、期刊状态；
- 不要为了“好看”使用无关校园风景；
- 所有图片必须裁切、压缩、统一圆角和比例；
- 不要把 respondent-level、个人敏感信息或身份证明放入 PPT。

如关键图片缺失，不阻塞 V1：先用带文字说明的占位框完成版式，并在交付说明中列出“若用户补图可替换的位置”。

# Task 1 — 建立母版与统一视觉

## 1.1 页面

- 16:9，13.333 × 7.5 in；
- 白底；
- 顶栏：x=0, y=0, w=13.333, h≈0.76；
- 顶栏深红；
- 页底线：x=0, y≈7.43, w=13.333, h≈0.04–0.05，同色深红。

## 1.2 顶栏模板

每页一致：

- 左侧小圆点：x≈0.42, y≈0.27, d≈0.18；
- Part 标题起点：x≈0.78, y≈0.14；
- 标题格式：
  - Slide 1：`Part1：扎根 —— 从专业第一到国发直博`
  - Slide 2：`Part2：求索 —— 以问题为锚，研究制度与公平`
  - Slide 3：`Part3：担当 —— 在集体中持续承担`
- 右上角放北大/国发官方标识，宽约 0.55–0.75 in，高度不超过顶栏；
- Logo 统一白色版或反白版；若无合适反白版，使用简化白线版/单色版，不要贴白底方块。

## 1.3 分隔线与标签

- 次级分隔用暖金色虚线或点线；
- 红色胶囊：深红填充、白字、圆角；
- 数字胶囊：白底、深红描边、深红大字；
- 阴影轻微，透明度高；
- 不使用厚重立体阴影。

# Task 3 — Slide 2 制作（全场 C 位）

## 3.1 页面目标

让评委记住的不是“两篇本科论文”，而是：

> **已经围绕“制度与公平”形成初步一致的研究关切。**

本页视觉权重最高，允许信息最多，但仍要留白。

## 3.2 顶部核心句

正文顶部 y≈0.96–1.45，居中：

> **聚焦社会公平正义，关注制度安排如何转化为个体层面的机会与结果差异。**

建议 20–23 pt，bold。

其中“社会公平正义”“制度安排”“机会与结果差异”用深红或加粗，不要全部上色。

## 3.3 左右双栏

中间 x≈6.67 使用一条非常浅的竖向点线，从 y≈1.65 到 6.45。

### 左栏：司法公平

区域：

- x≈0.55
- y≈1.65
- w≈5.75
- h≈4.85

顶部红胶囊：

> **司法公平**

右侧或下方大数字：

> **100万+**

数字下：

> 企业经济纠纷裁判文书

中部提出研究问题，字号 19–21 pt：

> **司法裁判歧视如何被量化与识别？**

其下用 2–3 个小标签：

> 文本分析　|　聚类　|　实证识别

底部结果标签：

> **毕业论文：优秀 · 92 分**

如有真实论文图/匿名化裁判文书截图，放在栏内右上角约 1.6–2.0 in 宽；否则用“文书 + 天平”极简线性图标，透明度低，不喧宾夺主。

### 右栏：空间公平

区域：

- x≈7.02
- y≈1.65
- w≈5.75
- h≈4.85

顶部红胶囊：

> **空间公平**

大数字：

> **100万+**

数字下：

> 平台二手房交易记录

中部研究问题：

> **行政边界如何塑造空间不平等？**

方法标签：

> 行政边界　×　断点回归

底部状态标签：

> **相关成果经修改后投稿《Nature Cities》**

若有真实 RDD 图或论文图，优先使用；否则用“城市轮廓 + 虚线边界 + 两侧点云”的示意图。示意图只能表达识别设计，不得伪装成实际结果。

## 3.4 底部共同逻辑

y≈6.55–7.15，横跨页面，做成简洁逻辑线：

> **制度安排 / 制度边界 → 机会与资源配置 → 公平结果**

左中右三个节点即可。

推荐：

- “制度安排 / 制度边界”深红；
- 中间深灰；
- “公平结果”深红。

这条线是本页“升格”的关键，不可删除。

## 3.5 动画

建议：

1. 顶部核心句；
2. 左栏；
3. 右栏；
4. 底部共同逻辑。

# Task 5 — Speaker Notes / 逐页讲稿

若环境允许，创建 `国奖答辩/SPEAKER_NOTES.md`。

要求：

- 总时长目标 2:40–2:50；
- 不照念 PPT；
- 每页只解释 1 个核心命题；
- 开头 15 秒内说出“本科专业第一 + 国发博士选拔笔试第一”；
- 科研页必须明确说出“两项工作共同关注制度如何影响公平结果”；
- 最后一页不再重复所有荣誉。

建议节奏：

### Slide 1：约 45 秒

核心表达：

> 我本科专业排名第一，并在国发院博士研究生选拔中以夏令营笔试第一获评优秀营员。过去一年，我通过港大交换进一步拓展经济学训练，并逐步完成从本科生向博士研究者的过渡。

### Slide 2：约 75 秒

核心表达：

> 我最持续关注的问题是社会公平正义。过去一年，我分别从司法和城市空间两个维度开展大规模微观实证研究：一项研究司法裁判歧视，一项研究行政边界造成的空间不平等。虽然问题不同，但共同关心的是制度安排如何转化为个体层面的机会和结果差异。

然后用 20–25 秒各讲一项，方法点到为止。

### Slide 3：约 40 秒

核心表达：

> 在学术之外，我本科四年持续承担团支书工作，上一学年带领班级连续第二年获示范班集体，同时承担党支部工作，并在毕业时获评中国人民大学优秀毕业生。进入国发院后，我也继续承担研究生党支部工作。

### 收尾：10 秒

> 未来，我希望从中国现实问题出发，在更加规范的经济学训练中持续研究制度、发展与公平。谢谢各位老师。

V1 导出 PDF 后逐页截图检查。

# Task 7 — V2 视觉微调

V2 不再改叙事逻辑，重点只做：

- 对齐；
- 留白；
- 字号；
- 图片裁切；
- 胶囊尺寸；
- 红色使用比例；
- 分隔线粗细；

# Final Acceptance Criteria

最终提交前必须全部满足：

1. 只有 3 页，无独立封面；
2. 视觉语言统一，三页像同一套模板；
3. 每页只有一个最重要的信息中心；
4. 大数字和证据图服务叙事，而不是堆砌；
5. 不出现旧学年课程成绩表；
6. 不出现未经确认的论文结果或荣誉；
7. 不把《Nature Cities》投稿写成发表/录用；
8. 不把现任党支书包装成上一学年成果；
9. 2:50 内可讲完；
10. PPT 与 PDF 都可正常打开，字体和图片无错位。
